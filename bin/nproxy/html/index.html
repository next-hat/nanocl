502

Bad Gateway

If you see this page, the nanocl proxy received an invalid response from the upstream server (502 Bad Gateway). This usually means the upstream service is down, unreachable, or returned an unexpected response.

Possible actions: verify the upstream service is running, check network connectivity, or review the proxy configuration and logs.
