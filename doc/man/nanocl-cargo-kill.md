# Cargo kill

# NAME

kill - Send a signal to a cargo by its canonical key

## SYNOPSIS

**kill** \[**-s**\|**--signal**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION

Send a signal to a cargo by its canonical key.

## OPTIONS

**-s**, **--signal** *\<SIGNAL\>*  
Signal to send (default: SIGKILL)

**-h**, **--help**  
Print help

\<*KEY*\>  
Canonical key of the cargo to signal
