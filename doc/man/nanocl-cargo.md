# Cargo

# NAME

cargo - Manage cargoes

## SYNOPSIS

**cargo** \[**-h**\|**--help**\] \<*subcommands*\>

## DESCRIPTION

Manage cargoes

## OPTIONS

**-h**, **--help**  
Print help

# SUBCOMMANDS

cargo-list(1)  
List existing cargo

cargo-create(1)  
Create a new cargo

cargo-start(1)  
Start cargoes by canonical keys

cargo-stop(1)  
Stop cargoes by canonical keys

cargo-restart(1)  
Restart cargoes by canonical keys

cargo-remove(1)  
Remove cargoes by canonical keys

cargo-inspect(1)  
Inspect a cargo by its canonical key

cargo-patch(1)  
Update a cargo by its canonical key

cargo-history(1)  
List cargo history

cargo-revert(1)  
Revert cargo to a specific history

cargo-logs(1)  
Show logs

cargo-run(1)  
Run a cargo

cargo-stats(1)  
Show stats of cargo

cargo-help(1)  
Print this message or the help of the given subcommand(s)
