# Cargo revert

# NAME

revert - Revert cargo to a specific history

## SYNOPSIS

**revert** \[**-h**\|**--help**\] \<*KEY*\> \<*HISTORY_ID*\>

## DESCRIPTION

Revert cargo to a specific history

## OPTIONS

**-h**, **--help**  
Print help

\<*KEY*\>
Canonical key of the cargo to revert

\<*HISTORY_ID*\>  
Revert to a specific historic
