# Context list

# NAME

list - List contexts

## SYNOPSIS

**list** \[**--wide**\] \[**-h**\|**--help**\]

## DESCRIPTION

List contexts

The compact table shows names, endpoints, and the current selection. Use
`--wide` to include descriptions. Contexts do not store creation timestamps.

## OPTIONS

**--wide**\
Show context descriptions alongside endpoints

**-h**, **--help**  
Print help
