# Cargo patch

# NAME

patch - Update a cargo by its canonical key

## SYNOPSIS

**patch** \[**-i**\|**--image**\] \[**-e**\|**--env**\]
\[**-v**\|**--volume**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION

Update a cargo by its canonical key

## OPTIONS

**-i**, **--image** *\<IMAGE\>*  
New image of cargo

**-e**, **--env** *\<ENV\>*  
New environment variables of cargo

**-v**, **--volume** *\<VOLUMES\>*  
New volumes of cargo

**-h**, **--help**  
Print help

\<*KEY*\>
Canonical key of the cargo to update
