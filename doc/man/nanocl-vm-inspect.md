# Vm inspect

# NAME

inspect - Inspect a VM by canonical key

## SYNOPSIS

**inspect** \[**--display**\] \[**-h**\|**--help**\] \<*KEY*\>

## DESCRIPTION

Inspect a VM by canonical key

## OPTIONS

**--display** *\<DISPLAY\>*  
Display format  

  
\[*possible values: *yaml, toml, json\]

**-h**, **--help**  
Print help

\<*KEY*\>  
Canonical key of the object to inspect
