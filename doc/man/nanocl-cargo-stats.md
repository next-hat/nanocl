# Cargo stats

# NAME

stats - Show stats of cargo

## SYNOPSIS

**stats** \[**--no-stream**\] \[**-h**\|**--help**\] \[*KEYS*\]

## DESCRIPTION

Show stats of cargo

## OPTIONS

**--no-stream**  
Disable streaming stats and only pull the first result

**-h**, **--help**  
Print help

\[*KEYS*\]
Canonical keys of cargoes whose stats to show
