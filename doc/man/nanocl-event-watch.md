# Event watch

# NAME

watch - Watch for new events in real time

## SYNOPSIS

**watch** \[**--plain**\] \[**-h**\|**--help**\]

## DESCRIPTION

Watch for new events in real time

## OPTIONS

**--plain**\
Print one line per event with its local timestamp, reporting node, severity, action, actor, and message. By default, watch prints the full event in the configured output format.

**-h**, **--help**  
Print help
